# Leaky integrate-and-fire & Hodgkin–Huxley

Neuron models from scratch in Python:

- **LIF neuron** driven by DC and Gaussian white-noise currents
- F–I curves, inter-spike intervals and spike irregularity (CV of ISI)
- Ornstein–Uhlenbeck input
- **Hodgkin–Huxley** dynamics at low and high input current
- A short EEG part: spectrum and spectrogram

`lif_and_hodgkin_huxley.ipynb` has the code, `report.pdf` the answers. The EEG part expects `EEG-1.mat` next to the notebook (not included).

Neuroscience, Learning, Memory & Cognition course, Sharif University of Technology.
